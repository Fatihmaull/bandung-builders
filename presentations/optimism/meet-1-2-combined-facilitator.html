Blok 1 · 0:05–0:20 · 15 menit

Meet 1 essentials — EVM + OP Stack

Mode: Talk + 1 demo · Slide: Meet 1 → #block-a + #block-b + #live-block

1a. EVM = state machine (7 menit)

Gambar di whiteboard:

Transactions → EVM (deterministic) → new state

3 kalimat wajib peserta hafal:

  1. EVM = mesin state deterministik — input sama → output sama di semua node.
  2. Gas = meteran compute; storage mahal, calldata murah.
  3. Account: EOA (private key) vs Contract (code + storage).

Skip: daftar opcode, Merkle trie detail — cukup sebut “Solidity compile jadi opcode, tiap baris = gas”.

1b. Kenapa OP Sepolia? (5 menit)

Diagram rollup singkat:

User → Sequencer → eksekusi L2 → state root → L1 Ethereum

Poin cohort default:

  • OP Sepolia = testnet OP Stack (parent dari Base, Mode, Zora).
  • Faucet: Superchain Faucet — login GitHub, tanpa mainnet ETH.
  • Chain ID 11155420, RPC https://sepolia.optimism.io.

Skip: perbandingan panjang Base vs OP — cukup 1 kalimat: “Base = branded OP Stack; kita belajar di induk stack-nya.”

1c. Live block OP Sepolia (3 menit)

Di slide Meet 1, klik Fetch block number — atau di terminal:

cast block-number --rpc-url https://sepolia.optimism.io
Checkpoint verbal

“Angka ini sama di seluruh dunia. Itu determinisme.”

Facilitation

Tips facilitator biar efektif

  • Jangan ulang kemarin. Buka dengan “kemarin = Web3 overview; hari ini = builder setup.”
  • Hands-on > slide. Target 50+ menit keyboard aktif (cast + forge).
  • Satu checkpoint keras: akhir Blok 5, semua angkat tangan yang forge test pass — yang belum, tutor lanjut offline.
  • Defer dengan jelas. Bilang apa yang sengaja ditunda ke rumah (skill mapping, boilerplate walkthrough) supaya peserta tidak merasa “kecolongan”.
  • Pair programming. Web2 kuat + Web3 baru = 1 pasang; percepat faucet & install issues.
  • Projector: terminal font besar, dark mode, zoom 150%+.
