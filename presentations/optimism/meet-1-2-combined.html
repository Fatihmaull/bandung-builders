Meet 1 essentials

The EVM as a deterministic state machine

The Ethereum Virtual Machine is a global state machine. Same starting state + same input → every node computes the same next state. That determinism is the foundation of everything we build. 

Transactions → EVM (deterministic) → new state
Interactive · One transaction at a time
STATE @ block N
Alice: 100 ETH
Bob: 50 ETH
Counter: 0
→
STATE @ block N+1
Alice: 100 ETH
Bob: 50 ETH
Counter: 0
Three sentences to remember
  1. EVM = deterministic state machine — same input → same output on every node.
  2. Gas = compute meter — storage is expensive, calldata is cheap.
  3. Accounts: EOA (private key) vs Contract (code + storage).

Solidity compiles to opcodes. Every line you write maps to gas.

Why OP Sepolia?

Rollups & the OP Stack

A rollup executes transactions off L1 with cheap fees, then posts a summary back to Ethereum. L1 remains the security anchor.

flowchart LR users["L2 Users"] -->|"transactions"| seq["L2 Sequencer (OP Stack)"] seq -->|"execute"| l2exec["Cheap L2 execution"] l2exec -->|"state root"| l1["L1 Rollup Contract"]

OP Sepolia is the testnet for the OP Stack — the same framework behind Base, Mode, and Zora. Our cohort default because:

  • EVM-equivalent — same Solidity, Foundry, and Wagmi as Ethereum.
  • Superchain Faucet — GitHub login at console.optimism.io/faucet, no mainnet ETH required.

Config

foundry.toml — three sections that matter

[profile.default]
solc_version    = "0.8.24"
optimizer       = true
optimizer_runs  = 200

solc_version is pinned to 0.8.24 — workshop policy. Do not upgrade unprompted.

[rpc_endpoints]
op_sepolia = "${OP_SEPOLIA_RPC_URL}"

Alias for --rpc-url. Value comes from .env in tracks/optimism/.

[etherscan]
op_sepolia = { key = "${OP_ETHERSCAN_API_KEY}", chain = 11155420, ... }

Enables forge verify-contract on OP Sepolia Etherscan (Meet 8).

OpenZeppelin lives in lib/ via remappings — installed with forge install.
