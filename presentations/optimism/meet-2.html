Block A · 20 min

The Foundry toolbox

ToolPurpose
forgeThe build & test runner. Compiles Solidity, runs unit tests, broadcasts deploy scripts.
castThe Swiss Army knife. Make RPC calls, encode/decode calldata, sign messages, send txs.
anvilA local Ethereum node. Forks any RPC, prints private keys for testing, fast block times.
chiselA REPL for Solidity. Useful for explaining language features.
For Hardhat refugees

forge is your npx hardhat. cast is your ethers.Contract. anvil is your hardhat node. Written in Rust, much faster, tests are themselves Solidity (no JS context-switch), and the cheatcodes are unmatched.

Live demo on projector

forge --version

cd contracts
forge build
ls out/StakingProtocol.sol/
cat out/StakingProtocol.sol/StakingProtocol.json | jq '.abi[0]'

Notice the build output is JSON — ABI + bytecode + metadata. This is what your frontend will consume. The ABI lives at contracts/out/<file>.sol/<contract>.json and we copy the .abi field into frontend/src/abi/.

Block B · 30 min

Anatomy of foundry.toml

Open contracts/foundry.toml on the projector. Hover the blocks below to see why each line is the way it is.

Interactive · Click any block to see the explanation
[profile.default]
src             = "src"
out             = "out"
libs            = ["lib"]
test            = "test"
script          = "script"
solc_version    = "0.8.24"
optimizer       = true
optimizer_runs  = 200
evm_version     = "paris"
  • solc_version pinned to 0.8.24. Workshop policy. Unpinned ^0.8.x produces different bytecode in 6 months.
  • optimizer_runs = 200 — OZ default. Tells the optimizer to assume each function will be called ~200 times.
  • evm_version = "paris" — safest cross-OP-Stack choice.
[rpc_endpoints]
op_sepolia = "${OP_SEPOLIA_RPC_URL}"
anvil        = "http://127.0.0.1:8545"

These are aliases. Now anywhere a Foundry command wants --rpc-url, you can pass op_sepolia instead of the full URL. ${VAR} is shell env substitution; Foundry reads from a sibling .env when you source ../.env. 

[etherscan]
op_sepolia = { key = "${OP_ETHERSCAN_API_KEY}", chain = 11155420, url = "https://api-sepolia-optimism.etherscan.io/api" }

OP Sepolia Etherscan implements the Etherscan v2 API — same auth header. The same forge verify-contract flag works against OP Sepolia Etherscan because of this block. Without it, you'd be passing --chain-id 11155420 --verifier-url ... on every verify command. 

remappings = [
    "@openzeppelin/=lib/openzeppelin-contracts/",
    "forge-std/=lib/forge-std/src/",
]

When you write import "@openzeppelin/contracts/.../ReentrancyGuard.sol"; Solidity does not know what @openzeppelin means. Remappings teach it: the prefix resolves to lib/openzeppelin-contracts/. Foundry's forge install <repo> clones into lib/ automatically. 

[fmt]
line_length         = 120
tab_width           = 4
quote_style         = "double"
number_underscore   = "thousands"
multiline_func_header = "all"

Foundry ships its own formatter — forge fmt. Run it before every commit; we will enforce this in peer review.

Block C · 30 min

cast field trip on OP Sepolia

The point of this block is to make OP Sepolia feel real and reachable from the command line before you ever write a contract of your own.

C.1. Chain-level values

# Current block number
cast block-number --rpc-url https://sepolia.optimism.io

# Chain ID, confirming we're on OP Sepolia
cast chain-id --rpc-url https://sepolia.optimism.io
# -> 11155420

# Gas price (in wei; divide by 1e9 for gwei)
cast gas-price --rpc-url https://sepolia.optimism.io

C.2. Read someone else's contract

# Total supply of WETH on OP Sepolia
cast call \
  0x4200000000000000000000000000000000000006 \
  "totalSupply()(uint256)" \
  --rpc-url https://sepolia.optimism.io

# Your own ETH balance
cast balance YOUR_ADDRESS --rpc-url https://sepolia.optimism.io
Repeat after the facilitator

"With zero code, I talked to a contract on a real L2. No SDK, no npm install, no wallet. cast is my fastest debugging surface for the next four weeks."

Live cast call — from this browser

Real · WETH9.totalSupply() on OP Sepolia

Address 0x4200000000000000000000000000000000000006 · Selector 0x18160ddd

click to fetch

This does exactly what cast call does — a JSON-RPC eth_call against https://sepolia.optimism.io. The result is a 256-bit number returned as hex; we decode it to a decimal big-int and divide by 1e18 to format.

C.3. Decode calldata from a tx

cast 4byte 0xa9059cbb
# -> transfer(address,uint256)

cast --calldata-decode "transfer(address,uint256)" \
  0xa9059cbb000000000000000000000000aaaa...0064
Muscle memory you want by end of Week 1

See calldata → know what function. We will do it constantly when something reverts on testnet.

The 10 stops on the tour

Stop 1 · Repo root. Monorepo, two workspaces, one curriculum folder.
Stop 2 · .cursorrules. The most important file from an AI-pairing perspective. Verify your agent picks it up.
Stop 3 · foundry.toml. See Block B above.
Stop 4 · contracts/src/. Reference + exercise contracts; the interface documents public surface area.
Stop 5 · contracts/test/StakingProtocol.t.sol. Tests are themselves Solidity, in this directory, .t.sol suffix.
Stop 6 · contracts/script/Deploy.s.sol. Forge scripts are also Solidity, with vm.startBroadcast.
Stop 7 · frontend/package.json. Versions are pinned: Wagmi v2, Viem v2, RainbowKit v2.
Stop 8 · frontend/src/lib/. wagmi.ts + contracts.ts — single sources of truth.
Stop 9 · frontend/src/hooks/. Five hooks, each does one thing.
Stop 10 · frontend/src/app/. Layout, providers, minimal example page.
Wrap-up exercise · 5 min

Open your AI agent right now. Ask it: "In this repo, where do contract addresses live? Cite the file path." If the answer is anything other than frontend/src/lib/contracts.ts, your .cursorrules isn't loaded. Fix it now, before you leave the room.

Common pitfalls
  • "forge install doesn't find the package" — CWD must be contracts/, not repo root.
  • Remapping not found — remappings.txt AND foundry.toml must agree.
  • solc_version mismatch — auto_detect_solc = false is deliberate. Pin and stay pinned.
  • source ../.env on Windows native — use WSL2 or $env:VAR = "...".
