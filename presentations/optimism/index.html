This is the default learning path for Bandung Builders. Work from tracks/optimism/, deploy on OP Sepolia, and learn the OP Stack / Superchain stack that also powers Base, Mode, and Zora.

Faucet: Superchain Faucet (GitHub) · Explorer: sepolia-optimism.etherscan.io · Docs: docs.optimism.io

Why OP Sepolia is the cohort default
  • Superchain Faucet — GitHub login, no mainnet ETH or Coinbase account required.
  • OP Stack native — you learn the parent rollup framework, not just one branded instance.
  • Portable skills — same Solidity, Foundry, Wagmi; switch to Base later with config-only changes.
  • Superchain interop — bridging, shared security model, and ecosystem grants (RetroPGF, OP Atlas).
