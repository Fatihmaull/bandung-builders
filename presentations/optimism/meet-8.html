Pre-flight · 10 min

Sync & sanity check

OP Sepolia · 10 min

Superchain Faucet & last-mile wallet check

Before deploy, every builder confirms testnet ETH on OP Sepolia — not Ethereum Mainnet, not Base Sepolia. The cohort default faucet is the Superchain Faucet.

  1. Open console.optimism.io/faucet and sign in with GitHub.
  2. Select OP Sepolia (not OP Mainnet, not Base Sepolia).
  3. Paste the deployer address from your .env PRIVATE_KEY.
  4. In MetaMask, switch network to OP Sepolia — balance should show ≥ 0.05 ETH.
  5. Optional: bridge Sepolia L1 ETH via Superchain Bridge if faucet rate-limited.
Common mistake

ETH on Ethereum Sepolia L1 does not pay gas on OP Sepolia. You must claim on the Superchain Faucet or bridge L1 Sepolia ETH into OP Sepolia.

Block · 40 min

Contract deploy + OP Sepolia Etherscan verification

1. Deploy

cd contracts
source ../.env  # bash / WSL; on PowerShell: $env:PRIVATE_KEY="..."; ...

forge script script/Deploy.s.sol:Deploy \
  --rpc-url op_sepolia \
  --broadcast \
  --verify \
  --etherscan-api-key $OP_ETHERSCAN_API_KEY
What just happened?
  1. forge script ran Deploy.s.sol as a script — vm.startBroadcast → on-chain.
  2. --broadcast said: actually send the txs (without it, dry-run only).
  3. --verify handed source code + constructor args to OP Sepolia Etherscan in the same workflow.
  4. Output prints the deployed addresses. Copy them now.

2. Capture the addresses

You will see three addresses: stakingToken, rewardToken, StakingProtocol. Note them all — the frontend needs the staking-token + protocol addresses.

3. Verify (if --verify didn't auto-complete)

forge verify-contract \
  --chain-id 11155420 \
  --watch \
  --etherscan-api-key $OP_ETHERSCAN_API_KEY \
  <DEPLOYED_ADDRESS> \
  src/StakingProtocol.sol:StakingProtocol \
  --constructor-args $(cast abi-encode \
    "constructor(address,address,address)" \
    <STAKING_TOKEN> <REWARD_TOKEN> <OWNER>)

4. Sanity check via cast

cast call <STAKING_PROTOCOL> "rewardRate()(uint256)" \
  --rpc-url https://sepolia.optimism.io

cast call <STAKING_PROTOCOL> "owner()(address)" \
  --rpc-url https://sepolia.optimism.io
Verification stuck on PENDING?

OP Sepolia Etherscan can take 30–120s. Re-run with --watch and wait. If solc_version doesn't match what was on-chain, verification fails silently — confirm foundry.toml pins to 0.8.24.

Block · 30 min

Frontend deploy to Vercel

  1. From repo root, vercel link (one-time). Choose the frontend workspace as the project root.
  2. Set environment variables in the Vercel dashboard (Production scope):
    • NEXT_PUBLIC_WC_PROJECT_ID
    • NEXT_PUBLIC_STAKING_CONTRACT_ADDRESS
    • NEXT_PUBLIC_STAKING_TOKEN_ADDRESS
    • NEXT_PUBLIC_REWARD_TOKEN_ADDRESS
  3. Set Build Command: pnpm install --frozen-lockfile && pnpm --filter frontend build
  4. Set Output Directory: frontend/.next
  5. Trigger deploy: vercel --prod or push to main.
  6. Note the live URL.
A safer pattern: ABI snapshot

We already committed a snapshot of contracts/out/StakingProtocol.sol/StakingProtocol.json into frontend/src/abi/. That way Vercel doesn't need to compile Solidity at build time, and the frontend has a deterministic ABI checked into git.

If anything fails

Resilience

Disaster-recovery playbook

Click any disaster to expand its recovery procedure. Have these top-of-mind for the 10-minute window before judging.

▶ OP Sepolia RPC is down or slow

Switch RPC. Free alternatives: https://optimism-sepolia.publicnode.com, https://base-sepolia-rpc.publicnode.com, Alchemy / Infura free-tier. Update Wagmi config & redeploy. If too late to redeploy: switch to your recorded demo.

▶ Vercel build fails minutes before pitch

Roll back via Vercel UI. Each push has a previous Production deployment one click away. Don't try to fix the build on stage. Roll back, pitch the older but working version.

▶ Wallet connect modal fails (WalletConnect rate limit)

Use Coinbase Wallet browser extension. Doesn't go through WC relay — direct injection. Have it pre-installed in your demo browser.

▶ Stake tx reverts unexpectedly

Open the failed tx on OP Sepolia Etherscan/Sepolia. 90% of the time: ERC20InsufficientAllowance (forgot approve) or ZeroAmount (input field empty). Both are user-side; reset the form. If on-chain: switch to the demo recording.

▶ Contract has a critical bug discovered post-deploy

Don't pretend it's not there. Pause new stakes (no pause in MVP; set rewardRate to 0 + drain reward pool via owner). Redeploy from a fresh contract address. Update .env, redeploy frontend. Have this procedure pinned in your project README.

▶ Laptop dies / WiFi dies / projector dies

Have your phone hotspot ready. Have your deck on your phone (Google Slides). Have your demo video on your phone. The pitch goes on. The worst hackathon pitches are the ones where the laptop dies and the founder freezes; the best are the ones where the founder smiles, picks up the phone, and keeps talking.
